The offcial n8n node for [gotoHuman](https://gotohuman.com).

gotoHuman lets you easily add human review steps to your AI workflows.

Many built-in features:
- Approval policies
- Team collaboration
- Rich review interfaces
- with support for markdown, images, lists, tables, and more
- Slack integration
- Email notifications
- Response dataset
- REST API
- and more...

## Installation

In n8n, search for *gotoHuman* in the nodes panel and choose from the available actions and triggers.  
If you need to manually install the node first, use the following npm package name: `@gotohuman/n8n-nodes-gotohuman`
You can also read the [guide](https://docs.n8n.io/integrations/community-nodes/installation/) in the n8n community nodes documentation.

## Usage

Refer to our [documentation](https://docs.gotohuman.com/Integrations/n8n/) for detailed information on using this node.
